## 🚀 Featured Projects

### 🧠 [IAS-Overclockers-SoC](https://github.com/VladimirTM/IAS-Overclockers-SoC) — 16-bit CPU with Crypto Mining ASIP
A full **16-bit Von Neumann CPU** implemented in Verilog with a custom 56-instruction ISA, a Python-based assembler, and a SHA-256-inspired **MINE instruction** for hardware-accelerated cryptocurrency mining. Also ships with a complete Memory-Mapped I/O subsystem (keyboard, display, timer) and 524 passing tests across 24 module testbenches.

`Verilog` `Python` `Assembly` `Digital Design` `Make`

---

### 🎵 [ShazamFPGA](https://github.com/VladimirTM/ShazamFPGA) — Song Recognizer on FPGA
Built for the Digital Logic course — a Shazam-inspired **song fingerprinting and recognition system** running on an FPGA. Implements the Radix-2 butterfly FFT, builds spectrogram fingerprints, and matches against a database. A genuinely fun mix of signal processing and hardware design.

`Verilog` `Python` `SystemVerilog` `FPGA` `Signal Processing`

---

### 📡 [ProiectDSPLabs](https://github.com/VladimirTM/ProiectDSPLabs) — Real-Time MPU6050 Driver *(Published)*
An embedded driver stack for the **MPU6050 accelerometer/gyroscope** on ARM microcontrollers (LPC2148, LPC2294), designed for **predictable real-time response** in critical IoT applications. This work was co-authored and published in a peer-reviewed journal.

> 📄 *"Real-Time Communication Driver for MPU Accelerometer Using Predictable Non-Blocking"* — Stangaciu, Ghimpău, Sztanarec · [Computers, Materials & Continua, Vol. 85 No. 2 (2025)](https://www.techscience.com/cmc/v85n2/63847)

`C` `Embedded Systems` `ARM` `LPC2148` `LPC2294` `IoT`

---

### 🗺️ [TreasureHunt](https://github.com/VladimirTM/TreasureHunt) — OS Project: Multi-Process Treasure Hunt Manager
An **Operating Systems** course project built in C and Shell. Implements a full CLI-based treasure hunt management system backed by binary file storage and UNIX directory operations. Features a **Treasure Hub** interactive interface that forks a background monitor process, communicates with it via **pipes**, and collects results from multiple child processes running in parallel — one per hunt — for score aggregation. Covers forking, IPC, signals, symbolic links, and logging.

`C` `Shell` `UNIX` `Processes` `IPC` `Make`
